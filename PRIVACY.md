# Privacy

This document describes marketplace-level data boundaries. Each plugin may have
additional privacy documentation in its own directory.

The repository does not provide a telemetry service. Contributors must not
commit credentials, buyer information, payment payloads, local user profiles,
or generated test artifacts.

Runtime hosts, plugins, and connected services process data under their own
terms, organization settings, and privacy notices. Review the documentation of
the plugin and runtime in use before enabling account-connected operations.

Use [SECURITY.md](./SECURITY.md) to report a privacy or credential concern.
